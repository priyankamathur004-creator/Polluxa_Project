# Polluxa_Project

# End-to-End LinkedIn Agent Analytics Platform

##  Project Overview

This project is a **Power BI dashboard** built to analyze LinkedIn lead and agent performance. The dashboard helps track lead conversion, outreach activity, risk, and data quality.

##  Power BI

The dashboard includes:

- KPI cards for Leads, Contact Rate, Connection Rate and Conversion
- Lead funnel and segment analysis
- Agent performance analysis
- Risk Score, Risk Band and Ghost Ratio
- Data Quality (DQ) analysis
- Interactive filters for Industry, Seniority, Country and Lead Status
- DAX measures for business KPIs and calculations

##  Python

Python was used for basic data preparation and analysis, including:

- Reading and cleaning CSV data
- Handling missing values
- Basic data validation
- Calculating and preparing analytical metrics
- Working with SQLite data
- Exporting processed data for Power BI
